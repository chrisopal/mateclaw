# 本地制造成本分析工具

输入沿用本任务 Excel 的「成本原始明细」和「产量原始数据」两个工作表。主流程为上传 → 校验 → 选择产品/月 → 查看趋势与变动归因 → 导出 Excel/独立 HTML。示例与真实上传明确区分。

采用 Python 标准库 HTTP 服务与 openpyxl 处理 Excel；前端使用原生 HTML/CSS/JavaScript 和由真实结果绘制的 SVG，无数据库、CDN、模型接口。相较 Streamlit，本方案不新增网页框架依赖；相较并入 MateClaw，独立目录可直接运行和迁移。仅绑定本机回环地址，上传数据保存在当前进程内存，最近 8 份可刷新回读，重启后清除。

## 页面与状态

单页工作台：顶部上传/模板/示例操作，随后是产品/月选择、紧凑指标、趋势、贡献图、原因文字及明细表。空白、校验失败、读取中、成功、缺少上月、离线报告均有明确状态。导出跟随当前选择，离线 HTML 内嵌数据及脚本可继续筛选，但不能调用服务器操作。

界面使用企业蓝色、纯色面板、细边框、14px 正文；响应系统深色偏好；桌面并列图表，小屏单列，明细表只在自身区域滚动。文件内容作为文本显示。

## 计算约定

单位成本=同产品同月制造成本/合格产量，不纳入期间费用。只比较相邻自然月，不跨缺失月份。多条同科目记录按耗用量加权价格。变动项按价格→投产单耗→良率顺序拆解；固定/混合项按费用额→产量分摊拆解；独立列出金额舍入差异。新增/消失科目按费用额与产量项处理，并提示归因局限。量纲/性态冲突阻止分析；同一产品跨月保持计量单位。

Excel 导出为当前输入的分析快照，带原始表、全部月度分析、全部归因明细、当前筛选的图表页和口径说明。修改原始表后需要重新上传分析，不宣称 Excel 自动重算整套 Python 逻辑。

## 验收

用既有 1000 条样本比对 48 个月度结果及 44 组归因；测试多条加权、缺列、重复产量、金额不平、月份缺失、公式输入、新增科目和零产量。真实浏览器完成模板/示例/上传/筛选/刷新/导出/离线 HTML 路径；导出回读核对原始条数、数值和原生图表。检查桌面及手机无页面横溢出。无前端编译步骤，执行 Python unittest、compileall 和 JS 语法检查。
