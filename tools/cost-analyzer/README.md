# 本地制造成本分析工具

上传 Excel 原始成本和产量数据，在网页中查看单位成本、趋势、科目贡献和原因分解，导出含原生图表的 Excel 或可离线打开的 HTML。中文界面，文件不发送到外部服务。

## 启动

本机 macOS 可双击 `启动成本分析.command`；脚本优先使用项目虚拟环境，再使用已装 openpyxl 的 Python，最后使用本机 Codex 的配套 Python。启动后打开 http://127.0.0.1:8765 。终端保持打开；按 Ctrl+C 停止。

其他电脑安装 Python 3.10+，在本目录执行：

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python app.py
```

Windows 使用 `.venv\Scripts\activate` 激活，或直接 `.venv\Scripts\python app.py`。端口被占用时运行 `python app.py --port 8766`。已有服务无需重复启动。

## 使用

1. 点击「体验示例」查看既有1000条模拟成本数据；或下载空模板及示例文件。
2. 填写「成本原始明细」「产量原始数据」。保留第一行列名，上传 `.xlsx`（最大10MB，单表最多20000条）。旧分析工作簿也可直接上传，工具只读两个原始表。
3. 校验通过后选择产品和月份。趋势展示所有可用月份，因素贡献只对比相邻自然月。
4. 导出 Excel 或 HTML。导出跟随当前选择；Excel 包括全部产品/月份的分析明细、原始数据与当前选择的图表。HTML 内嵌数据、样式、脚本，断网后双击打开仍能切换筛选。

上传内容保存在当前 Python 进程内存中，保留最近8份；网页刷新可回读，服务重启后需重新上传。不同浏览器标签可分别查看各自报告。网页提供的示例明确标为模拟数据，不属于真实经营结论。

## 输入与计算口径

- 单位成本 = 当月同产品制造成本 / 合格入库产量。期间费用单独汇总，不进入产品成本。
- 每产品每月一条产量记录，投产量 = 合格量 + 报废量，投产及合格量必须大于0；不支持在制品变动或停产分摊。
- 数量、价格、金额必须为非负纯数值，金额与数量×单价允许0.01元舍入差；公式输入需粘贴为值。负数冲回需先按业务口径净额整理。
- 同月同产品同科目允许多笔成本，按耗用量加权单价。同产品同科目跨月保持类别、性态、耗用单位一致。同一产品保持名称、产量单位一致。
- 变动项依次拆为价格、每投产件耗用、良率影响；固定/混合项拆为费用额和产量摊薄。交互项按此顺序归属，金额舍入差另列，分解结果逐组校验。
- 新增、消失或零耗用的变动科目按费用额与产量归因，明确提示不推断价格。缺相邻上月时不计算环比，也不将缺失数据当成0。
- 各产品分别比较；Excel 总览只比较与所选产品计量单位相同的产品，避免把元/件与元/吨混在同一轴。
- 结果是算术归因，需结合采购、工艺、维修与报废记录验证真实经营原因。

Excel 是分析时点的快照，修改导出文件的原始表不会自动重新执行 Python 分解，须重新上传。网页没有数据库、登录和远程多人服务，默认仅本机访问。

## 验证与结构

```sh
python -m unittest discover -s tests -v
python -m compileall -q app.py analysis.py reports.py
node --check static/app.js
```

- `app.py`：本地 HTTP 服务、上传、模板及导出。
- `analysis.py`：输入校验、归集、单位成本和因素分解。
- `reports.py`：原生图表 Excel、独立 HTML、空模板。
- `static/`：离线可用网页与 SVG 图表，无 CDN 或前端构建步骤。
- `examples/`：本次对话使用的1000条模拟数据。
- `tests/`：分解、校验及Excel回读测试。

当前版本为独立小工具，没有修改 MateClaw 的业务模块、依赖或启动流程。

MateClaw 工程门禁在本目录或质量控制文件变更时执行上述单测与语法检查；缺少兼容的 openpyxl 环境会阻止提交。CI 使用隔离 Python 环境，业务数据验收仍需另行执行。
