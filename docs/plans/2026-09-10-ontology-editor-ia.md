# 本体编辑页 UI Blueprint

基线 27bb7b18。用户明确授权编辑页信息架构重整、删减解释并改善来源导引。

视觉主张：沿用 MateClaw 扁平企业主题，以完整工作画布、清楚导航和少量蓝色主操作建立层级。
内容结构：页头仅标题/保存状态及当前动作；主体按「本体设计 → 规则依据 → 校验发布」分区。设计区以图为主，基本信息和高级 OWL 明细为次级入口；规则依据默认展示已有依据，新增流程渐进展开；校验与发布聚合在最后一步。
交互主张：使用现有标签切换、折叠和弹窗的短过渡；保留图谱缩放/拖动；无装饰动效、不引入新依赖。

保留：路由、权限、草稿/CAS/幂等恢复/发布机制、图谱、所有高级能力、来源快照/复核和API字段。
调整：编辑页信息架构、动作优先级、来源表单布局、用户文案、当前规则定位与分区切换。
收起：顶栏低频操作、全文技术说明、底层投影覆盖信息和表达式明细；保留会影响用户判断的错误/风险提示。

来源名称：公理→规则（必要处保留OWL）；来源类型→依据形成方式，EXTRACTED=文档提取、EXPERT=专家确认、INFERRED=推理生成。底层数据含义不改，不把三类说成文件格式。
输入流程：选择规则、填写原文与形成方式、展开文档定位信息（知识库ID/文档ID/摘要/位置），确认关联。没有文档检索API时不伪造选择器；精确定位字段仍真实可填且提交前可见可检查。

验收：组件行为回归、定向ESLint/类型/构建；真实浏览器设计编辑保存、规则跳转来源/绑定/复核、校验发布入口、更多菜单、1366/1440/1920/390、light/dark/焦点/溢出。仅临时标签改变viewport，原生用户标签不变。测试后自动本地提交，不推送。

## 用户补充后的调整

主界面改为「业务模型 / 参考资料 / 检查发布」，不暴露 IRI、公理、摘要值、码点、OWL 构造符。对象仅填名称，标识在后端稳定生成；关系选择起点/终点，属性选择所属对象/内容类型；规则以关系和数量要求表达。新增 model-edits 结构化命令后端映射 OWL，复用原 CAS 与幂等事务。OWL 编辑/导入导出集中到低频工具面板。
参考资料不再采用手填技术定位字段方案：真实知识库/文档选择、原文引用，系统处理摘要/位置与权限核对。
