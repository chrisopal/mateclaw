# E3b：概念限制规则编辑

承接已批准增强方案第 7 节，基线 e2ccc56a。本批交付命名概念的直接对象属性限制：存在、全称、最小/最大/精确基数的新增与逐条替换。

- 由标准表达式投影识别可编辑规则，不从公理字符串猜测结构。仅根文档、无注释、命名主体/属性/限定概念、完整投影的直接限制进入表单。
- 复用现有公理 REMOVE + ADD 保存、CAS 和待定请求恢复机制。主语 IRI 不变；不移植旧公理来源；修改后重新核对来源并校验。
- 嵌套、带注释、导入及其他构造继续保留原文与高级入口；本批不实现通用树编辑或删除概念。
- 支持基数零值；区分全称限制与存在、OWL 基数与业务单值。所有表单修改先预览，禁止重复/无变化保存。
- 验收：逻辑和组件测试、类型/构建检查；真实浏览器新增与替换、刷新/独立 GET 保真、CAS、响应丢失恢复、已发布只读、窄屏和原生窗口交还。
- UI 测试使用临时标签，finally 关闭并返回用户原生标签，不改变用户窗口视口。通过后自动提交 Git。
