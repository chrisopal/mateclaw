# E3a 简单定义编辑实施边界

基线 905a5740。按既定顺序推进 E3 简单编辑；用户已要求继续开发并在验证后自动提交。

- 检查器内编辑选中 IRI 的名称、描述、命名父类、对象/数据属性命名 domain/range。每条既有公理单独选择，多 domain/range 不折叠覆盖。
- 新增简单注释/关系和替换均先预览；只生成目标公理的 REMOVE + ADD。复杂表达式、带注释公理保持高级入口；不在此轮增加删除、基数或批量 IRI 重命名。
- 名称语言与显示语言区分，显示采用精确语言、同主语言、无语言、其他标签回退。IRI 不变，punning 的注释共享须说明。
- draft.edit 统一保护 dirty/busy/publicationPending/权限；不确定提交保存原请求并提供明确恢复动作，CAS 不自动重放，表单保留输入。
- 替换后重新读取服务端索引和来源；提示旧依据不会自动证明新语义。不迁移业务事实。
