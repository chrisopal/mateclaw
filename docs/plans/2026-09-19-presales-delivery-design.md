# 售前方案到成果闭环（已确认范围）

保留现有服务、身份权限、数字员工运行机制、不可变方案与文件摘要审批。首轮实现任务专属结构化产出、持久化后台任务、受控 ppt-master-plus 转换；不新增消息队列或独立模型执行栈。

- ADR-05（Accepted）：任务先持久化再交给后台执行；认证身份由服务器捕获，后台重查成员及来源权限。重启中断任务明确终止，不自动重复模型调用。代价是本阶段不承诺断点继续生成。
- ADR-06（Accepted）：按任务校验结构和来源引用；方案与演示都是待人工复核的产出。人工评审与 AI 建议分开，不允许员工审批发布。
- ADR-07（Accepted）：制稿请求仅返回选定方案 ID 与页面；服务端从快照绑定原方案事实，避免模型重复生成整份方案导致截断或事实漂移。员工编写 SVG 页面，平台只运行受信技能包的固定完整性检查、质量检查和原生 PPTX 转换程序，不接受任意命令、路径或外部 SVG 资源。保存技能版本、输入摘要、页面及 PPTX 摘要；失败不回退旧生成器。

验收：请求迅速返回任务；重复提交不重复运行；后台身份和 Workspace 不混用；重启有终态；取消后成果不入库；引用越界拒绝；方案版本和 PPT 字节可回读；草稿与审批门禁保持；真实员工生成实例有记录。
