# 本体建模企业工作台

范围：当前 semantic-m1 工作树的本体草稿和已发布版本页面。保留 OWL 文档权威、CAS、权限、发布、导出、来源审查；不修改后端协议或业务事实。

默认结构视图：左侧可搜索的概念/关系/属性目录，中间可缩放的结构图，右侧所选节点/连线的定义与相关规则。概念与本体个体独立筛选；关系明确显示定义域/值域，不能表达成业务事实或必填约束。复杂表达式保留原文及未投影提示。

普通编辑：表单新增概念、对象关系、数据属性，使用现有原子公理编辑 API。未保存全文时禁用表单，避免覆盖。高级入口保留完整 OWL 文本、公理表和标签编辑。发布版本使用相同只读结构浏览器。

视觉：沿用企业主题、Element Plus 和现有 CSS tokens，连续面板、细分隔线、紧凑工具栏；窄屏依次排列目录、画布、详情。不引入依赖。

验收：投影不得从共现签名虚构关系；IRI/literal 安全；punning 分类型；新增表单真实落库/刷新回读；既有草稿与权限测试；类型检查、构建、lint；实际浏览器桌面/窄屏截图。复杂 OWL 的全量可视化编辑不属于本次简化表单能力。
