# T08 UI Blueprint

范围：版本页→应用知识库→既有抽取/迁移工作台；不修改本体建模画布或实体审核。
视觉：沿用企业主题与 Element Plus；扁平、紧凑，单一主操作，不增加装饰动画。
内容：版本页主操作“应用到知识库”；弹窗固定目标版本、选择应用知识库、当前绑定与执行动作。参考资料知识库不自动作为应用知识库。
交互：复用弹窗/下拉原有过渡与按钮状态；每次切换 KB/工作区清除旧结果；忙碌防重入；断网后读回绑定恢复。
复用：KnowledgeBindingPanel 兼容既有入口，加入固定版本模式；非空不同版本仅允许差异与迁移入口；抽取页显示模型名称版本和不可用原因。
验收：新绑定/同版本恢复/非空换绑拦截/版本差异/迁移目标、开关与模型条件、开始失败重试取消、权限、失焦、390/768/1440/2560 与深色。
