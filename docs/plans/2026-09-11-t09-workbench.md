# T09 执行与 UI 蓝图

基线：8ae930ca，复用 semantic-m1 工作树及持久化库。

目标：从候选的实体核对到待审核、已确认、修订/撤回和授权语义上下文形成可操作链路。
保持：已有实体/事实/证据/版本权威、工作台导航、主题、审核权限和未知时间策略。
调整：候选实体选择使用实体 ID；提供新建/已有/暂不确定，原始提及与 OWL 映射由既有后端处理；事实用业务描述，技术内容折叠；证据入口连到既有抽屉。
不采用：按同名自动合并、另建实例库、绕过正式版本校验、将模型样例直接写入事实。

视觉：沿用扁平企业工作台，一处核对表单配来源证据；短标签、单一提交审核主操作。
内容顺序：来源 → 对象身份 → 事实与适用时间 → 保存核对 → 提交审核 → 查看状态/历史。
交互：沿用抽屉/选择器过渡与加载反馈；保留失焦标签、脏表单保护；390px 单列，桌面双列，无新动画。

实施：
1. 核查后端映射、样例交接、上下文权限缺口，复用现有能力补齐。
2. 候选身份核对与业务化事实/历史展示，恢复证据入口。
3. 回归：同名不误合并、已有实体复用、未确定不可提交、来源/版本/时间门禁、审核后查询与撤回排除。
4. 真实浏览器与持久化回读、响应式、构建及提交。真实模型语义效果另行声明，不用测试模型替代。
