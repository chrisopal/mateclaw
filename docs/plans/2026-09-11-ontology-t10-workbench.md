# T10：资料变化后的增量建模

基线 de1dd6fa，继续使用 semantic-m1 和现有持久化库。

1. 定义变化：复用本体来源复核的新旧快照，将受影响规则及精确来源版本交给建模任务；在既有业务建议面板确认，不修改已发布旧版本。
2. 事实变化：复用图来源变化清单，明确查看旧结论与新原文后，提交既有事实变更申请；与模型定义路径区分，不自动接受。
3. 已删除、不可访问、版本又变化的来源单独显示；不能据无法读取的内容自动推断新结论。
4. 同复核事件重试恢复既有任务/申请；来源再次变化必须重新检查，禁止旧请求覆盖新状态。

保留：原本体/事实/证据存储、人工发布及修订审核、权限和幂等机制、企业UI布局。
调整：把“重新建模”从状态标记连接到实际可继续的任务；为事实变化提供业务化修订入口。
不做：自动发布、全量覆盖、T11版本迁移、资料内容不可用时猜测变化。

验证：修改、删除、撤权、新旧版本隔离、重复事件幂等、来源再变、两条UI路径、持久化重启回读、企业版构建。
