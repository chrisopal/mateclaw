# T07 UI Blueprint

基线 35b06cdc。沿用现有扁平企业工作台、编辑器导航与响应式布局。

- 保留：业务模型/建模建议/业务规则/参考资料工作区、发布操作恢复语义。
- 调整：检查发布页以一次“运行检查”生成统一报告，四个紧凑状态行展示模型结构、模型逻辑、业务规则、参考资料。
- 收起：技术诊断放在详情中；领域覆盖仅提示由业务确认，不能冒充自动检查结论。
- 退出编辑器主流程：独立 T06 逻辑按钮，避免与统一报告并列；诊断 API 和组件测试保留。
- 交互：无装饰动画；按钮忙碌与结果状态明确，未检查、失败、过期均不能解锁发布；刷新读取服务端报告。
- 发布弹窗显示已通过检查的前提，服务端仍独立强制核对；关闭后回到触发位置。

验收：一次检查→四层结果→刷新读回→发布；失败/过期→禁止发布→修改重检；窄屏与桌面控件完整，旧结构-only报告不能解锁按钮。
