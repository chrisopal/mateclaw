# B2：自然语言与资料建模交付

范围：T03、T04，基于 `dd10a428`。包含本轮用户反馈的编辑布局及窄屏适配修复；B3—B5 不在本批范围内。

## 已实施

- 列表、编辑器和知识库进入同一建模任务；支持自然语言及选择资料，不要求用户提交 OWL。
- 建模师恢复任务、分页发现资料、按固定摘要分块读取、提交业务建议。用户陈述单独标记，资料摘录由服务端验证。资料访问遵守员工权限。
- 建议先保存、后人工接受；问题未回答不能接受。拒绝、过期、刷新和对话返回保留任务状态。后端将业务命令转为原有 OWL 草稿，不另建模型主库。
- 严格拒绝未知命令字段，避免模型声称建立继承关系、实际却静默丢弃字段。规范化签名集合顺序，保证精确重放结果稳定。
- 建议放入独立页签，确认后返回业务模型。需求默认折叠，统一内边距及操作基线，修复空字段、类型名称和已确认状态显示。
- 窄屏目录默认折叠、保留搜索，筛选和布局设置可展开，缩放控件保持一组。大幅宽度变化或跨断点重新适配画布，小幅变化保留用户平移。

## 验证

- 后端：30 项相关测试通过，包含工具权限、业务命令、来源、并发、恢复、精确重放及集合顺序。
- 前端：本体目录全部 121 项测试通过；相关 ESLint、类型检查、生产构建通过。未新增依赖。
- 真实 DeepSeek：自然语言任务、双 TXT 资料任务均完成建议生成和人工确认。双资料识别“最多两个 / 最多四个”冲突并等待回答；实例示例没有写成类型或正式事实。
- 实际 OWL 回读：两条流程均保存继承及文本属性。确认前草稿未修改；确认后刷新、服务重启后的任务、版本与文档摘要一致。
- 浏览器：390、768、1440、1920、2560 宽度无横向溢出；顶部与模型操作右边线均为 1374px（1440 视口）。1920→390 时图形缩放从 158% 调整为 47%，六个节点完整显示，缩放按钮同组。浅色及深色截图已检查。

运行入口：`http://127.0.0.1:5189`，后端 `18109`。验收数据库固定为 `data/semantic-owl-runtime/database.mv.db`，每次更新前离线备份，未恢复旧数据，也未使用临时库替代验收。

## 复核入口

验收目录：`output/ui-acceptance/2026-09-11-b2/`。

- `verify_persistence.py`：只读核对两条任务及草稿，输出 `persistent-readback.json`。
- `replay-ui.js`：从已登录浏览器创建独立测试窗口，复核恢复、键盘切页、对齐、宽度、缩放、搜索与取消，结束后关闭测试窗口。
- `coverage.json`：23 个浏览器检查通过，2 个现场场景未运行（单独 viewer 会话、真实超过一页的资料选择）；相应权限和分页契约已有组件/集成测试，不能称为全 UI 无缺口验收。
- `editor-desktop-final.png`、`editor-mobile-final.png`、`proposal-dark.png`：布局证据。
- `natural-accepted.ofn`、`source-accepted.ofn`：实际生成并回读的 OWL。

## 边界与后续

已有员工的知识库禁用设置保持不变；旧建模师需在员工设置中显式启用。新建建模师默认启用知识库能力，仍遵守可见范围。

本批“结构检查”仍不等于推理已执行。草稿推理、统一检查发布门禁属于 B3；知识库实体审核和应用闭环属于 B4。本次目标数据库验收是本地持久化 H2，不代表生产 MySQL 容量或全量浏览器角色矩阵通过。

后续维护：浏览器尺寸验收使用独立窗口，不在用户使用中的标签页施加固定视口，避免测试状态影响用户观察。
