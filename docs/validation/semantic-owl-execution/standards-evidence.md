# 标准能力的实际证据与剩余门槛

实现采用完整 OWLAPI 文档模型，不以自定义类/关系列表裁剪 OWL 2 DL 构造。标准合法性由 profile 校验明确报告，形式推理使用受限 HermiT 子进程。

`evidence-index.json` 记录最近读取的独立测试报告及摘要，并非一次最终发布检查。OWL-001–078 的参数化测试覆盖解析、RDF/XML/Functional 往返及编辑后既有公理保留；OWL-079–087 有专门边界测试，但部分行的全部规格仍需逐项补齐。最初 435 个 ID 是规格数量，不能当作实际通过数量。

真实 worker 测试覆盖 SEM-01–08 区分、开放世界、functional 导出的身份一致、显式不同个体、不一致与不可满足类区分、数据值相等、domain/属性链、非简单属性基数、无效字面量、负断言。另有子进程超时、并发限制和 Spring Boot 嵌套依赖启动验证。合法公理注释（如单位）作为标准注释保留，不因它们改变逻辑含义；普通文本中的 Import/Ontology 词语不会被误判成导入指令。

尚未形成完整的外部 W3C 一致性测试集运行证据、全部 datatype/facet 语义矩阵、每个规格的负例和上下文单独验收。当前不得宣称“完整 OWL 2 DL 推理认证通过”。不支持、解析失败、profile 不合法、超时、资源限制各自返回明确状态，不转换成错误的逻辑 false。
