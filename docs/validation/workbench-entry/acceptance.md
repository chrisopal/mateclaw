# 知识工作台入口调整

## 设计及实现

Wiki 绑定卡片去掉额外水平外边距，与上方 Wiki 管理卡片对齐；“打开知识工作台”使用右上角主按钮。版本选择与绑定维护操作集中在下一行，保留固定版本及不可换绑状态，移除重复帮助段落。窄屏允许标题和操作换行。

本体管理每行提供独立“知识工作台”按钮，通过对话框展示关联知识库名称、本体版本、启用状态，再进入对应图谱。复用现有查询和工作台路由，不增加后端接口。停用绑定禁用进入操作；无绑定显示空状态和知识库入口。组件随关闭或工作区切换取消请求，避免旧工作区内容回填。

主要文件：KnowledgeBindingPanel.vue、OntologyList.vue、OntologyWorkbenchDialog.vue、ontologyWorkbench.test.ts 及中英文语言文件。此前未提交的 M6 内容保留。
