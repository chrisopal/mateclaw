# 区分资料知识库、版本化本体与事实语义图

状态：Proposed。日期：2026-09-05。细化 LOCAL-SEM-03/04/05，适用于当前 MateClaw 仓库内新增语义核心。

## 决定

复用 MateClaw 知识库作为资料和资源授权边界；本体定义在同工作区可复用的类型及规则；每个 KB 首期最多启用一张绑定精确已发布本体版本的语义图。已存在数据的图不自动换绑新本体版本。

事实采用独立身份和不可变修订，来源采用固定内容快照。候选、正式事实及冲突处理分开；原生 Wiki 实体抽取和置信度只能提供候选依据。业务属性及关系的权威写入统一在 Statement，不同时维护可写实体属性袋。

## 取舍

把所有内容扩展到现有 Wiki Entity/Relation 表看起来更短，但会把文档抽取、业务约束、治理历史和上游修改耦合在一起。独立语义记录增加少量存储与映射代码，换取清晰的事实权威、版本和证据边界。

一个工作区一个总图可较早实现跨知识库关系，却要求立即解决细粒度来源权限和跨库实体对齐；首期采用单 KB 图。同一本体的规则复用不共享实例身份或权限。

发布新本体自动升级全部图会使历史事实的含义变化；精确版本绑定保留解释依据，代价是后续需要明确迁移功能。快照增加存储成本，但仅保存可变 chunk 引用不能支撑历史证据。

## 后果与验收

跨图引用、无证据确认、隐式本体升级、候选覆盖已确认事实均拒绝。确认事务必须在当前图状态下重验约束并防止并发冲突；缺失支持或个人撤权不能通过物理删除历史来处理。

完整模型、状态与反例见[领域模型](../architecture/2026-09-05-semantic-domain-model.md)。本 ADR 不修改外部 Semantica4j 的设计或任务卡。
