# ADR-0002：下一阶段采用有界本体增强和只读影响分析

## 状态

Accepted（2026-09-08）。用户授权“开始执行”后，M4 已实施；实际验收与边界见 [M4 验收](../validation/ontology-m4/acceptance.md)。关联 [M4 设计](../architecture/2026-09-08-ontology-m4-design.md)。

## 背景

`fe638a97` 已有本体发布、精确绑定、人工候选、证据、冲突、可信查询和管理 UI。下一步可以增强建模、自动生成候选或升级已有图。系统必须保持独立核心与宿主边界，避免新规则悄悄重解释既有事实；上阶段仍有 Kingbase 未实机验证的限制。

## 决策 A：M4 先增强模型，后续再抽取与迁移

建议 M4 交付术语提示、有限值约束、模板包和影响分析。M5 从固定快照生成待审核候选；M6 单独处理已有图的版本升级。

- 收益：先明确“合法事实”的契约，复用现有完整治理链。
- 代价：M4 不减少文档到候选的人工录入量；若业务优先级是批量录入，应在本 ADR 接受前调整排序。
- 备选：优先自动抽取具有较快演示收益，但实体消歧、证据、成本及模型失败成为主范围；优先迁移则涉及历史与恢复，改动更大。

## 决策 B：确定性类型规则，不引入推理/表达式引擎

使用 JDK-only core 值对象与验证器实现 TEXT 枚举和 DECIMAL 范围；alias/deprecated 仅影响提示与检索。无继承、任意脚本和必填事实检查。沿用关系数据库与已有 UI 库。

- 收益：规则可测试，所有写入口和诊断复用同一实现，无新基础设施和执行任意代码风险。
- 代价：不能表达跨实体组合条件或复杂因果；有明确需求时再新增具名规则，不能用自由脚本补洞。
- 备选：动态规则引擎/OWL/RDF 会引入新的模型、求值和运维边界，当前场景没有足够依据承担成本。

## 决策 C：定义格式显式版本化，旧修订不改写

旧 JSON 缺版本视为 format 1；新定义 format 2。统一读取/默认值，禁止旧客户端无提示覆盖新版草稿。业务本体 v2 不等于 JSON format 2；两者各自演化。

- 收益：历史定义、绑定和幂等结果仍可解释；防止 DTO 演进静默丢字段。
- 代价：增加兼容适配和双格式测试；写入新格式后不能直接用旧后端回滚。
- 备选：批量重写旧定义会破坏不可变历史；完全忽略未知字段会掩盖错误及数据丢失。

## 决策 D：本体包只创建新草稿，不建立动态依赖

包是受限 JSON 文件，只有可移植定义及描述；导出发布修订，导入预览后新建本体草稿，保留来源摘要。包 digest 是完整性/幂等依据，不是签名。

- 收益：用户能明确控制复制和发布，没有跨工作区事实、权限及动态升级传播。
- 代价：复制后各自演化，不能自动拉取原模板更新；M4 不提供字段级合并。
- 备选：包仓库、继承或远端 import 有版本解算和供应链成本；整库导出会混合模型和业务证据。

## 决策 E：影响分析与发布、迁移分开

按图比较实际绑定定义和目标定义，输出变更类别与 current 数据符合性，包含待审核内容及失效证据支持的当前确认修订。报告带版本/时间/完整性，不能作为迁移命令。旧非空图仍禁止换绑。

- 收益：管理员看得见影响，新版本可以独立发布，不扩大写锁或更改历史。
- 代价：用户仍需等待 M6 才能升级旧图；诊断结果会过期，需要重算。
- 备选：仅比较 JSON 无法告诉用户受影响事实；直接改 graph 绑定会使旧事实在没有转换、审核和证据处理的情况下被新规则重解释。

## 安全、运行与接受条件

所有接口执行当前工作区/角色及资源检查；不暴露不可见绑定图的聚合信息。包不执行代码、不访问远端，拒绝超限及未知格式；写入复用本体治理/命令事务。保留 feature flag，关闭新入口不移除新格式读取能力。

本 ADR 已按 M4 建模/复用优先、质量根因作为验收场景执行。实现验收必须覆盖双格式、约束共用、导入恢复、版本过期、权限负例、真实 H2/MySQL、两种 UI profile，并明确 Kingbase 证据。

## 实施补充

- 未新增数据库迁移和依赖；模板导入复用命令/治理表，短事务以工作区行锁串行化，READ_COMMITTED 避免 MySQL 锁等待后读到旧快照。
- 影响分析使用只读 READ_COMMITTED 事务，结束前清理 MyBatis 会话缓存并重新读取图版本、草稿版本与权限；4.8 秒主动预算和 5 秒事务超时。事实/提案各限 10000，明细上限 200 与完整统计分开。
- SINGLE 冲突复用核心判定，采用时间扫描和按值分组，避免密集槽位的二次方两两扫描；提案按 operation_id 读取，复用现有 graph/operation 索引。本阶段不新增专用状态索引。
- DECIMAL 合法边界在摘要中按数值规范化；1.0 与 1.00 不产生伪造的不同模板身份。导出保留模型表达，导入不改写源本体。
- 影响报告不计算支持状态变化，只检查实体与当前事实/提案的目标约束；证据增加不递增图版本不影响这些输入，当前 ACCEPTED 无论 SUPPORT_LOST 与否均参与。历史迁移、支持重算和自动换绑不属于该快照承诺。
