## 如何复建与核验

在仓库根目录执行：

```sh
node docs/user-guide/ontology/build.mjs
node output/ui-acceptance/2026-09-13-manual/verify.cjs
```

构建复用现有 marked 依赖。生成的 index.html 内嵌全部正文图片和示例文本附件，可以离线打开。验证脚本检查本地页面、目录跳转、每张图片的加载与放大关闭、示例附件下载、桌面及窄屏布局。结果写入同目录的 verification-result.json。

原始采集脚本与页面记录在 `output/ui-acceptance/2026-09-13-manual/`；采集脚本需本地服务、现有受控账号、指定工作区及案例数据，不是通用初始化脚本。身份凭据仅在内存中使用。
