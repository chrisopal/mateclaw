# Score rules

Store numeric score claims as decimal strings. `null` means the source does not provide a calculable value. Every total check must list `criterionIds` for exactly the criteria included in that subtotal: sum that selected set with `BigDecimal`, and keep calculated total and difference `null` if a selected score is unknown. A scored parent may be checked on its own when the source scores it independently. Never select both a parent and descendant in the same check, and do not assume that all leaf criteria belong in every subtotal. Use separate checks for each independently stated section subtotal. Compare a known sum with its separately quoted stated total using `difference = statedTotal - calculatedTotal`.
