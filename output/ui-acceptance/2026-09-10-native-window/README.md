# 原生窗口裁切修复

用户反馈版本页右侧操作和详情栏显示不完整。现场读回：页面模拟视口 2400px，实际窗口 1920px，DPR 被模拟为 1。响应式测试污染了用户标签；先前的模拟视口宽度断言没有覆盖真实窗口交还。

已在相同登录上下文恢复一个 `viewport=null` 的原生标签，打开同一只读版本页并关闭受污染标签。真实尺寸为 1920×882、DPR 2；刷新后保持原生尺寸。页面右界为 1920，详情栏右界 1872，最右侧操作按钮 1873，均完整显示。

## 防复发修改

`../2026-09-10-e2-expressions/run.js`、`wide.js`、`e2-regression.js` 改为在临时标签执行尺寸模拟，最外层 finally 关闭临时标签并返回用户原生标签。复用现有登录上下文，无凭据导出。应用 CSS 和业务代码本次没有修改。

曾尝试直接清理 CDP 尺寸覆盖，短时看似恢复，但刷新仍会重新应用旧视口；该方案已弃用，未进入提交。截图采集与交还均应检查真实 outerWidth、innerWidth 和 viewport=null，不能只比较 DOM 的内部宽度。
